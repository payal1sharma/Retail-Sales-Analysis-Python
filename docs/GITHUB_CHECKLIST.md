# GitHub Upload Checklist

1. Create/open the repository for the project.
2. Upload the project folders:
   - data
   - docs
   - notebooks
   - outputs
   - powerbi
   - sql
   - src
   - legacy
3. Upload README.md, requirements.txt and .gitignore.
4. Do not upload `.venv/`.
5. Do not upload passwords or MySQL credentials.
6. Keep the included dataset only if the dataset license/usage terms allow redistribution.
7. In GitHub, make README.md the landing page.
8. Add 3–5 screenshots from `outputs/charts/`.
9. Add the Power BI `.pbix` only after creating the real dashboard in Power BI Desktop.

Suggested repository description:
"End-to-end retail business intelligence project using Python, SQL/MySQL, statistics, customer analytics, forecasting and Power BI."

Suggested topics:
python, sql, mysql, pandas, power-bi, data-analysis, business-intelligence, forecasting, customer-analytics
